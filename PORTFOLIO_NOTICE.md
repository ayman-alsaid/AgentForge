# Portfolio Review Notice

The production source code for **AgentForge** is maintained in a private repository and is not distributed publicly.

This public repository is maintained as an **Engineering Evidence / Technical Case Study** for professional review.

It documents, where supported by the project record:

- system architecture;
- execution and replay flows;
- engineering decisions;
- alternatives and trade-offs;
- testing and controlled verification;
- deployment model;
- security and trust boundaries;
- known limitations;
- live demonstration links.

It intentionally does **not** publish:

- proprietary production source code;
- credentials or secrets;
- private repository links;
- sensitive operational configuration;
- implementation details whose disclosure would weaken commercial or security boundaries.

The purpose is to give Senior Engineers, CTOs, technical reviewers, collaborators, and prospective employers enough concrete evidence to evaluate the engineering work while preserving the private production implementation.

## Evidence language

Claims in this repository are written using explicit evidence boundaries such as:

- IMPLEMENTED
- TESTED
- VERIFIED IN A CONTROLLED RUN
- DEPLOYED
- MEASURED
- ESTIMATED
- PLANNED
- NOT YET VALIDATED

The strongest claim used should be the strongest claim the available evidence supports — not the strongest wording the product story would benefit from.
